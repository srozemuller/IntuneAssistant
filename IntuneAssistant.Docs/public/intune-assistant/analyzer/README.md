# Analyzer

The Analyzer section contains tools that inspect your Intune environment and surface actionable recommendations.

- [Group to Filter Analyzer](group-to-filter-analyzer.md) — Identifies which dynamic groups can be replaced by Intune Assignment Filters.
- [Error Finder](error-finder.md) — Lists the failed health scripts and app installs in your tenant, with what each error means and how to fix it.
- [Compliance Coverage](compliance-coverage.md) — Explains, per device and per assignment, why Intune reports a device as having no compliance policy.
